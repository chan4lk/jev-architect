# Tasks: BISTEC Architect — Tauri desktop app (local MiniCPM + Jev decisions)

**Change:** 001-bistec-architect-agent
**Created:** 2026-09-23
**Total Tasks:** 15

## Summary

Six waves:

1. Scaffold and catalogue.
2. The four independent core adapters (Jev, Ollama, documents, store and secrets).
3. Pure decision logic (question builders, rules, scoring).
4. Pipeline, rendering, and Tauri commands.
5. The UI screens.
6. Calibration assets, end-to-end smoke test, README.

All tests run offline, using fakes for Jev and Ollama.
